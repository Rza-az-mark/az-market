# 🛒 AZ Market - Azərbaycan Onlayn Marketplace Platforması

AZ Market — alıcılar, müstəqil satıcılar (vendors) və kuryerləri bir araya gətirən müasir e-ticarət platformasıdır.

## 🚀 Layihənin Əsas Xüsusiyyətləri
* **Çoxsatıcılı Sistem:** Fərqli mağazaların öz paneli və məhsul idarəetməsi.
* **Vahid Səbət və Ödəniş:** Müxtəlif satıcıların məhsullarını tək ödənişlə almaq imkanı.
* **İnteqrasiyalar:** Yerli ödəniş sistemləri və SMS bildirişləri.

## 🛠 Texnoloji Stək
* **Frontend:** React / Next.js
* **Backend:** Node.js (Express) / PostgreSQL
* **Dizayn:** Tailwind CSS
